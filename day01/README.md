# Day 01 – Personal website

## The task
Sign up to GitHub and build a personal website with GitHub Pages and Jekyll. The site should describe my academic background, interests, plans and goals for the course. Then open an issue on the course repository with links to the site and its repository.

## What I did
1. Created the repository [gordonlevitan/gordonlevitan.github.io](https://github.com/gordonlevitan/gordonlevitan.github.io) and turned on GitHub Pages.
2. Tried a couple of Jekyll site drafts, then moved the site files to the repository root, because GitHub Pages builds from there.
3. Added a profile photo, my lab (Rybtchinski lab), education, plans, goals for the course, a link to my Google Scholar profile, and an "Outside the lab" section.
4. Opened the submission issue [Code-Maven/wis-python-course-2026-10#20](https://github.com/Code-Maven/wis-python-course-2026-10/issues/20).
5. Following the lecturer's feedback ("add more content and improve the design"), I added content, redesigned the site and commented on the issue.

Website: https://gordonlevitan.github.io/
